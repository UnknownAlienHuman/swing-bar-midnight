# SwingBarMidnight

Melee swing-timer addon for Midnight. Its TOC notes optional phase anchoring from SpellActivationOverlay glow, player proc auras, and optional range gating.

**Version:** 0.8.1
**Interface:** 120000
**SavedVariables:** `SwingBarMidnightDB`

## Install

Copy `SwingBarMidnight` to `World of Warcraft/_retail_/Interface/AddOns/`, enable it, and reload the UI.

## Use

Use `/swingbar` to access the addon's command handler. The checked-in options module creates a settings category with controls and an Apply action. The main frame supports a resizer according to `core.lua`.

## Current development status

No specific unfinished implementation items were found in this directory. The remaining documented uncertainty is live verification of swing timing, optional phase anchors/range gating, frame resizing, and options application on the target client.
